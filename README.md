# Discourse Foundation

The classic Discourse theme that is well-suited to customization for your community’s specific needs.

This theme is minimal and inherits its styles directly from Discourse core. It serves as a foundation for further customization.

## Installation

1. In Discourse admin: **Admin → Themes → Install → From a git repository**
2. Paste the repo URL and install.
3. Select **Foundation** in the theme list.

## Structure

```
.
├── about.json          # Metadata
├── locales/            # Locale strings
└── common/
    ├── common.scss     # Custom styles
    └── head_tag.html   # Custom head tags
```
